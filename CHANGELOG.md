# Changelog

All notable changes to the `backend-nestjs-developer` skill are documented here.

This file follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-02

Initial versioned release.

### Added

- `SKILL.md` with backend-engineer conventions and workflows for advisory, implementation, debugging, and scaffolding tasks.
- Tactical DDD guidance for simple projects and full bounded-context architectures.
- Bootstrap conventions for API versioning, Helmet, CORS, validation, response formatting, exception formatting, and throttling.
- Authentication guidance for JWT cookies and static or dynamic RBAC.
- Database, logging, error-handling, cross-context, controller, alias, naming, and anti-pattern references.
- `README.md` with the skill overview, installation options, requirements, and repository structure.
